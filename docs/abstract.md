ABSTRACT

Narrative inconsistency detection is an emerging area within the field of criminology and forensic linguistics, aimed at enhancing the analysis of textual evidence in criminal investigations. This project, titled “AI-Based Narrative Inconsistency Detection for Criminology Using NLP,” presents an intelligent system that leverages Natural Language Processing (NLP) and transformer-based models to automatically identify contradictions and logical gaps in criminal narratives.Criminal investigations heavily depend on narrative data such as witness testimonies, suspect statements, police reports, and court transcripts. These narratives often contain inconsistencies due to deception, memory limitations, or misinterpretation. Traditional forensic analysis methods are manual, time-intensive, and prone to human bias, making automated solutions both necessary and impactful.The proposed system utilizes Natural Language Inference (NLI) techniques to perform semantic reasoning across statements, detecting contradictions and evaluating narrative coherence beyond isolated sentence pairs. Unlike existing approaches that focus primarily on short text segments or non-criminal domains, this system is designed to analyze complete, real-world criminal narratives, incorporating cross-statement and contextual relationshipsBuilt using Python and modern NLP frameworks such as PyTorch and Hugging Face Transformers, the system aims to provide interpretable outputs that assist investigators in identifying suspicious inconsistencies efficiently. By combining scalability, domain adaptation, and explainability, this project offers a practical AI-driven solution for improving accuracy and decision-making in forensic analysis.
